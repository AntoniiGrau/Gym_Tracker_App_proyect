# My Tracker App proyect
Cross-platform gym management prototype developed using Django REST Framework and Flet (Python), featuring token-based authentication and custom load tracking.

## Key Features
- **Secure Authentication:** User accounts managed via Django REST Framework Token Authentication.
- **Personalized Workouts:** Flexible filter settings so clients can only see their custom prescribed exercises.
- **Progress Tracking:** Interactive visual logging system for tracking daily sets, repetitions, and weights (kg).
- **Streaming Technique Videos:** Streaming integration to play instructional videos in real time without downloading heavy media files.

## Tech Stack
- **Backend:** Python / Django REST Framework / SQLite3
- **Frontend:** Python / Flet (Adaptive UI for desktop & mobile)
- **Networking:** REST API / Token Auth
